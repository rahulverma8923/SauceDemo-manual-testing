# 🐞 Defects Identified

The testing process identified the following issues:

- Checkout process allows users to complete an order even when the shopping cart is empty.
- Reset App State clears the cart badge but does not immediately reset product buttons without refreshing the page.
- Checkout form accepts invalid characters and invalid ZIP/Postal Code without proper validation.
